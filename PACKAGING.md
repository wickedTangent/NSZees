# NSZees Packaging Guide

## DO NOT INCLUDE IN DISTRIBUTION

### Critical Exclusions
**NEVER** package or distribute these files:
- `*.keys` (prod.keys, title.keys, etc.)
- `config/settings.json` (developer's local settings, e.g. last-used input directory)
- `/logs/` directory
- `/output/` directory  
- `/temp/` directory
- Python `__pycache__/` folders
- `*.pyc`, `*.pyo` bytecode files

### Required for Distribution
- `bin/` — Portable Python runtime + nsz backend (python.exe, run_nsz.py, Lib/site-packages/nsz, PySide6, all companion files)
- `src/nszees/` — Application source code
- `assets/` — App icon (`icon.ico`, `icon.png`), used by the app window and the shortcut
- `config/` — Configuration directory (empty initially; `settings.json` is generated at runtime)
- `THIRD_PARTY_LICENSES.md` — Required: license/attribution notices for nsz, PySide6/Qt, and other bundled dependencies in `bin/`
- `COPILOT_BRIEF.md` — Optional developer reference

### User Must Provide
Users must obtain and place their own key files:
- `prod.keys` in the app root directory
- `title.keys` (optional) in the app root directory

Without `prod.keys`, NSZ compression/verification will fail.

## Packaging Checklist
1. ✅ Remove all `.keys` files from package
2. ✅ Exclude `/logs/`, `/output/`, `/temp/`, `config/settings.json`
3. ✅ Include full `bin/` directory with all NSZ portable files
4. ✅ Include `src/nszees/` with all Python modules
5. ✅ Include `assets/` (app icon), `run_nszees.py`, `launcher.py`, `NSZees-NoConsole.cmd`, `NSZees.bat`, and `Create_NSZees_Shortcut.ps1` at package root
6. ✅ Create empty `config/`, `logs/`, `output/`, `temp/staging/` directories
7. ✅ Add `README.md` instructing users to provide their own `prod.keys`
8. ✅ Include `THIRD_PARTY_LICENSES.md` at package root (required by nsz's MIT license and PySide6/Qt's LGPL-3.0 license)

## End-User Startup (Windows)
Preferred startup options:

- `NSZees-NoConsole.cmd` (recommended, launches via `pythonw.exe`)
- `NSZees.lnk` (icon shortcut, generated by running `Create_NSZees_Shortcut.ps1` once)
- `NSZees.bat` (fallback)

Do not ask users to run Python commands manually.
